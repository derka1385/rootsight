# Baseline diagnosis — before implementation

Base: `96cec66` on `nolann/home-scan-account`. Captured Home → Explore samples at 390×844, DPR 1, month 0, ideal watering. The existing 5173 server belongs to the other checkout, so this isolated checkout uses 5174.

1. **Leaf outline and perforations:** monstera leaves have parallel rectangular margin cuts, flat polygonal lobes, no enclosed fenestrations. Reference has curved fingers, oval interior holes, cupping, and tapered tips.
2. **Architecture:** the monstera is a low, radial umbrella with nearly horizontal blades. The reference has several unequal stems, staggered upright petioles, and asymmetric blade directions. A species-only seed cannot describe individuals.
3. **Count and density:** basil is a sparse single stalk in a large pot; its branching algorithm does not obey the observed leaf count. The reference is a cluster of stems with opposite leaves, substantial mature blades, and smaller growing tips.
4. **Cactus surface:** the barrel reads as a ribbed green dome with almost invisible tiny single spines. The reference has contrasting pale areoles and radiating spine clusters, prominent near the crown.
5. **Proportions and finish:** inferred maximum root dimensions produce oversized pots, especially basil and cactus. Fixed terracotta cannot describe the reference containers. Uniform green cannot encode patch variegation, localized yellowing, brown tips, or lighter undersides.
